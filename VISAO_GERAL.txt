🚀 COMEÇAR EM 3 PASSOS
═══════════════════════════════════════════════════════════════════════════════

1️⃣ INSTALAR NODE.JS (se não tiver)
   → Acesse: https://nodejs.org/ (versão LTS)
   → Ou execute: sudo apt install nodejs npm (Linux)

2️⃣ TERMINAL 1: Rodar Backend
   $ cd fastapi-avamud
   $ source venv/bin/activate
   $ uvicorn app.main:app --reload
   
   ✅ Estará em: http://localhost:8000

3️⃣ TERMINAL 2: Rodar Frontend
   $ cd avamud-frontend
   $ npm install (primeira vez)
   $ npm run dev
   
   ✅ Estará em: http://localhost:5173
   
   🌐 Abra: http://localhost:5173 no navegador

🐛 SOLUÇÃO DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════════════

❌ "npm: comando não encontrado"
   ✅ Instale Node.js (veja COMECE_AQUI.md)

❌ "Cannot find module"
   ✅ npm install

❌ "CORS error"
   ✅ Adicione CORS no backend (veja COMECE_AQUI.md)

❌ "Login não funciona"
   ✅ Verifique se backend está rodando (http://localhost:8000)
   ✅ Verifique se CORS está configurado

❌ "Porta já em uso"
   ✅ npm run dev -- --port 3000
